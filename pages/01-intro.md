# Slide Notes: Introduction

Welcome to the **Waterslide** presentation framework! This framework is designed to be agent-friendly and extremely simple to configure and customize.

## Key Features
- **No UI Flicker:** Slide HTML and dependencies are preloaded before rendering.
- **Separate UGC & Framework:** Custom slide changes are isolated to the `pages/` directory.
- **Controls Fade-out:** The interface fades out for clean fullscreen viewing and fades in on mouse activity.

> "A simple, clean foundation for creating presentations with zero fluff."

*Tip: Hover near the top-right to reveal the theme switcher and slide notes buttons.*
